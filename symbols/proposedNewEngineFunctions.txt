## Key Data Structures

### Opcode Table
Address: 0x014c1ac0
Entry Size: 16 bytes
Format: [handler_ptr (8 bytes)] [metadata (8 bytes)]

### ClientScriptState Structure (approx 0xC420 bytes)
Offset +0x100: Integer stack
Offset +0x10a8: String stack
Offset +0x8db0: Long stack

### Return Value Constants
Success (0): 0x01702e80
Yield (1): 0x01702f80
Error: 0x01701dc0

### Packet Handler Global Addresses
Handlers are registered at DAT_016f4xxx addresses:
- DAT_016f4940: Copy helper at 0x0018fb50
- DAT_016f4908: SET_VARP_SMALL at 0x001b9c70
- DAT_016f48c8: SET_VARP_INT at 0x001b9bc0
- DAT_016f4888: SET_VARP_LONG at 0x001b9ac0
- (etc - see packet handler agent report)

## Notes

1. The jag::packethandlers:: namespace is a proposed convention for organizing
   packet handler functions. The original source may use different naming.

2. Many functions have multiple clone variants in functions.txt - we have
   identified the primary versions.

3. Run FixNamespaces.java in Ghidra to convert :: in function names to proper
   namespace hierarchies.
